# Privacy policy: The Odd Department Autopilot

Last updated: 27 November 2026

The Odd Department Autopilot is a private tool used only by the owner of The Odd Department YouTube channel and Instagram account. It is not offered to the public.

## What it accesses

With the owner's permission, it uses the official YouTube Data API, the YouTube Analytics API and the Instagram Graph API in read-only mode to read the owner's own channel information: the list of videos, publishing status and schedule, and statistics such as views, watch time, likes, shares and comments.

## How the data is used

The data is used only to create private performance reports for the channel owner, so we can understand which videos work and improve future videos.

## Storage and sharing

The data is stored only on the owner's own computer. It is not sold, shared with third parties, or used for advertising.

The tool does not collect data about viewers beyond the totals and public comments that YouTube and Instagram show to the channel owner.

## Removing access

Access can be removed at any time from https://myaccount.google.com/permissions (Google) and from Instagram's Apps and Websites settings.

## Use of Google user data

The Odd Department Autopilot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
